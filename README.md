#  Custom Widget Plugin (WordPress)

A custom **WordPress Widget Plugin** that allows developers and site owners to easily add reusable widget content to their WordPress websites.  
This plugin is built using **core WordPress APIs**, following best practices for widget development.

It is ideal for learning **WordPress plugin development**, widget registration, and clean PHP structuring.

---

##  Features

- Custom WordPress widget creation
- Clean and modular PHP code
- Uses WordPress Widget API
- Easy to install and configure
- Lightweight and performance-friendly
- Compatible with modern WordPress versions

---

## Tech Stack

| Technology | Usage |
|----------|------|
| PHP | Plugin & widget logic |
| WordPress | CMS framework |
